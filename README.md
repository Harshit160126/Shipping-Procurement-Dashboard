# Shipping Procurement Dashboard | Excel & Power Pivot

An interactive **Shipping Procurement Analytics Dashboard** developed using Microsoft Excel, Power Query, Power Pivot, DAX, PivotTables, PivotCharts, and slicers.

This project demonstrates how shipping procurement data can be transformed into actionable insights for freight cost management, procurement savings, vendor performance, and shipment monitoring.

### Project Highlights

- **1,200 shipments** analyzed across 2025–2026
- **$9.33M** total freight budget
- **$8.12M** awarded freight spend
- **$1.21M** procurement savings
- **12.96%** savings rate
- **56%** on-time delivery rate
- **1,194 invoices** monitored

### Dashboard Features

- Monthly Freight Spend vs Budget
- Shipment Status Distribution
- Dynamic Top 5 Vendors by Freight Spend
- Freight Spend by Shipping Mode
- Interactive Year, Month, Shipping Mode, and Vendor slicers
- Dynamic KPI cards connected to the Excel Data Model

### Technical Implementation

- Connected synthetic procurement tables using Power Query.
- Established relationships in the Power Pivot Data Model.
- Developed DAX measures for financial and operational KPIs.
- Built interactive PivotCharts and slicer-driven reports.
- Designed a consolidated executive dashboard in Excel.

**Dataset:** Synthetic shipping procurement data created for portfolio and learning purposes.

**Future Scope:** Vendor performance analytics, invoice exception reporting, and Power BI dashboard development.
